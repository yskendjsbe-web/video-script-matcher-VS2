مطابقة الفيديو مع السكريبت

ارفع فيديو طويلاً مع سكريبت، ويختار لك الذكاء الاصطناعي اللقطات المناسبة بالدقيقة والثانية، ويركّب لك فيديو قصيراً.

النسخة الدقيقة (مجانية، GPU من Google)

تسمع الفيديو وتشاهده وتفهم السكريبت بأي لغة. تفتحها بزر واحد.

  1. اضغط الزر وادخل بحساب Google.
  2. اختر Runtime ← Change runtime type ← T4 GPU.
  3. اضغط Runtime ← Run all، ثم افتح رابط gradio.live الذي يظهر.
افتح في Colab

النسخة الخفيفة (داخل المتصفح)

تحتاج ملف ترجمة SRT بنفس لغة السكريبت، ودقتها أقل.
